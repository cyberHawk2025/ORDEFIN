ORDEFIN — CÓDIGO-FONTE

1. Instale o Node.js LTS 22.12 ou mais recente.
2. Se necessário, instale o pnpm 10: npm.cmd install --global pnpm@10
3. Abra esta pasta no PowerShell e execute:

   pnpm.cmd install --frozen-lockfile
   pnpm.cmd run check:types
   pnpm.cmd test
   pnpm.cmd run check:electron
   pnpm.cmd run build
   pnpm.cmd run desktop:start

desktop:start compila a interface e abre o aplicativo; não cria instalador.
Não publique dados financeiros pessoais, bancos de dados, backups ou credenciais.
